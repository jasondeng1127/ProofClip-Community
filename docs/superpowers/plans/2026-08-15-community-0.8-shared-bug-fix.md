# Community 0.8 Shared Bug Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复 Commercial 0.8 canonical upstream 的 OAuth 与 Outbox 共享缺陷，经现有 deterministic exporter 同步到 Community，并把离线测试与快捷键升级行为推进到可重新 freeze RC 的证据状态。

**Architecture:** OAuth 修复复用现有 Notion API 版本常量；Outbox 修复把 prerequisite failure 纳入现有 `attemptDelivery` failure/recovery 路径，并让 batch summary 使用实际 queued 数。Commercial 变更先形成干净 immutable commit，再由 Community `release/export-community.mjs` 生成源码与 provenance，不创建 Community product fork。

**Tech Stack:** Chrome MV3 JavaScript modules, Cloudflare Worker JavaScript modules, Node.js `node:test`, existing Community release exporter, Chrome profile upgrade rehearsal.

## Global Constraints

- 只修 OAuth、Outbox 及其最小 regression coverage；不做 release governance、CI、provenance redesign 或无关清理。
- OAuth 修复前必须有观察实际 outbound headers 的 failing test。
- Outbox 测试必须验证多记录 batch 的 failed、queued、persisted Outbox 数量分离及恢复链。
- Commercial upstream → existing Community exporter → Community tests；禁止手工复制绕过 pipeline。
- 不正式发布、不打最终 release tag、不把 rehearsal 标为 PASS。
- 保留当前 Community `extension/src/community-config.mjs` 的既有未提交修改，不覆盖或归因给本轮。
