# Security policy

Do not report a suspected secret exposure, OAuth weakness, token-vault problem, cross-extension CORS issue, or data-loss risk in a public issue. Use the repository host's private vulnerability-reporting feature when it is enabled; otherwise wait for a secure reporting channel to be documented.

Reports should include affected version, self-hosted deployment steps, expected and actual behavior, and minimal redacted evidence. Never include Notion access tokens, client secrets, vault keys, full captures, or personal workspace data.
