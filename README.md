# ProofClip Community

> Community 0.8 is a self-hosted evidence capture workflow for Chrome and
> Notion.

ProofClip Community captures a text selection, a visible image area, or a
cleaned page body/full page as browser-local evidence. You explicitly choose
when to send a record to a Notion Data Source that you authorize.

The Community edition is self-hosted: you own the Cloudflare Worker, D1
database, Notion OAuth integration, extension configuration, and data flow.
It is not a one-click or zero-config hosted service.

The self-hosted design has no dependency on an Official ProofClip Worker: a deployer owns the Worker, D1 database, Notion OAuth integration, extension configuration, and associated data flow. The Community 0.8 tree is generated by the deterministic pipeline in `release/` (see `release/README.md` and `release/out/community-0.8.0/PROVENANCE.json`, targetVersion 0.8.0) and has been swapped into `extension/` and `worker/`. Public-source and commercial-boundary gates are part of the release process.

Official ProofClip is a separate product line. Its domains, Cloudflare accounts, OAuth credentials, operations, release assets, and future product work are not part of this repository.

## Get started

1. Download the official Community 0.8.0 release ZIP.
2. Follow the [self-hosted deployment guide](deploy/README.md) to create your
   Worker, D1 database, Notion OAuth integration, and Worker secrets.
3. Load `extension/src` as an unpacked Chrome extension.
4. Connect Notion, select a Data Source, and save your first capture.

See [docs/architecture.md](docs/architecture.md) for the self-hosted boundary
and [Community 0.8.0 release notes](docs/release-notes-0.8.0.md) for the user-facing changes.
